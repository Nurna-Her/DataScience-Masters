## 📌 Acerca de
Este repositorio contiene un conjunto de algunos de los proyectos y ejercicios desarrollados como parte de mi Máster en Ciencia de Datos. El trabajo abarca múltiples asignaturas y demuestra diferentes etapas del flujo de trabajo en ciencia de datos:

1. **Recopilación de datos** – Adquisición y curación de conjuntos de datos.
2. **Limpieza y preprocesamiento de datos** – Manejo de valores faltantes, ingeniería de características y transformaciones.
3. **Análisis exploratorio de datos (EDA)** – Resúmenes estadísticos, visualizaciones e insights.
4. **Modelado** – Regresión, clasificación, clustering y otras técnicas de aprendizaje automático.
5. **Visualización y generación de informes** – Dashboards, PowerBI y gráficos interactivos.

## 📌 About

This repository contains a set of some of the projects and exercises developed as part of my Master’s degree in Data Science.  
The work spans multiple courses and demonstrates different stages of the data science workflow:

1. **Data Collection** – Dataset acquisition and curation.  
2. **Data Cleaning & Preprocessing** – Handling missing values, feature engineering, and transformations.  
3. **Exploratory Data Analysis (EDA)** – Statistical summaries, visualizations, and insights.  
4. **Modeling** – Regression, classification, clustering, and other ML techniques.  
5. **Visualization & Reporting** – Dashboards, PowerBI, and interactive plots.
