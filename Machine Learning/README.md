# 🤖 Machine Learning

## What will you find here?
> These files contain deliverable notebooks covering different ML techniques completed during the Master's in Data Science.

### The projects
Below is an overview of the notebooks available in this folder:

1. **Deep Reinforcement Learning I** – Deep reinforcement learning with DNQ.

This delivverable experiments with the usage of DNQ techniques (Simple, Dueling, Double) on a Pong game Gym environment.

2. **Deep Reinforcement Learning II** – Deep reinforcement learning with  SB3.

This deliverable experiments with stable baselines 3 and custom rewards and custom rewards on a modified Cartpole environment.

3. **Ensemble Learning** – Notebook on ensemble techniques.

The goal of this notebook is to explore and compare the performance of different ensemble-learning models for classification and regression problems. Includes some preprocessing and model tuning.

4. **Listening Patterns** – Analysis of listening patterns for recommendation algorithms.

The goal of this notebook is to uncover hidden patterns in unlabeled music-listening data using dimensionality-reduction and unsupervised learning techniques.


### ❗ Disclaimer
These projects were developed as course deliverables, and not as fully curated, end-to-end projects. 
As a consequence of this, most of these projects are only available in Spanish.
